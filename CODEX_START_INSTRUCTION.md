# Start Instruction

Start by reading `docs/00_READ_ME_FIRST.md`, `docs/PHASE_STATUS.md`, and open ADRs. Work only on the next unblocked phase. Inspect existing code before edits, preserve uncommitted user work, and never report an unavailable integration as completed. For a new provider, require an adapter, contract tests, cost/permission policy, sanitized events, and documentation. Do not deploy, alter DNS, buy domains, use paid APIs, or request secrets without explicit approval.
