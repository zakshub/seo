# First Vertical Slice

Input: authenticated owner starts an English/global public-source research run with a zero paid-provider budget. The worker records actual source queries/results/failures as evidence and must obtain three evidence-supported opportunities. Product strategy produces scorecards. Chief Intelligence creates review candidates. Owner approval atomically creates a Project and a queued `design.preparation.requested` task.

Out of scope: LLM calls, paid data, Figma writes, deployment, DNS, analytics connections, and artificial data. If a source cannot be used, the run explains why and may end incomplete rather than pretend success.
