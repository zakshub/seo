# Implementation Roadmap

Phase 0: documentation, monorepo, contracts, persistence/event foundation, policy engine, local environment, and Control Center shell. Phase 1: durable workflow, live activity, approvals. Phase 2: research. Phase 3: strategy. Phase 4: Figma/design/review. Phases 5–12: engineering, QA/technical SEO, deployment, measurement, growth, finance, learning, and controlled Auto Pilot.

Phases advance only when their acceptance criteria are evidenced; later adapters may be designed but not represented as active.
