# Frontend UX Specification

The Control Center primary navigation is Dashboard, AI Team, Opportunities, Projects, Design, Development, SEO Growth, Analytics, Deployments, Finance, Knowledge, Approvals, Activity, and Settings. Unimplemented areas show their real availability and setup requirement, never dummy metrics.

Dashboard presents Start System, mode, active agents, current task, workflow counts, approvals, portfolio, provider availability, spend/health alerts, and activity. Activity is a server-sent projection of persisted events. Opportunity detail shows evidence, source date, confidence, limitations, scorecard, and plain-language definitions. Tooltips define terms such as indexing, CTR, and canonical URL. Commands visibly explain their consequences and approval requirement.
