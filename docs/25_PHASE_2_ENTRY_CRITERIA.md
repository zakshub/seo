# Phase 2 Entry Criteria

Phase 2 does not begin because Market Study code exists or because three candidates were generated. One shortlisted opportunity must have an approval packet satisfying every gate below.

| Gate | Minimum acceptable evidence |
|---|---|
| Audience | A bounded audience, its problem language, and evidence showing it—not a generic persona |
| Search problem | Clear jobs/intents and representative query examples |
| Demand | Authorized evidence that demand exists; public-Q&A views alone are insufficient |
| Product/content gap | Specific weaknesses or unmet needs tied to captured pages/results/products |
| Competitors | Initial specialist and substitute landscape with dated source references |
| Information architecture | A testable page/tool/topic-cluster structure mapped to intent |
| Topic clusters | Initial clusters and long-tail/expansion logic without fabricated volume |
| Traffic surfaces | Identified acquisition surfaces and what evidence supports each |
| Feasible build | Bounded first release, relative build/maintenance cost, dependencies, and material risks |
| Unknowns | Critical unknowns resolved or explicitly accepted by the owner |
| Decision | An unexpired, scoped owner approval for the selected opportunity |

Automatic readiness is forbidden when search-demand evidence, exploitable gap evidence, or owner approval is missing. The correct recommendation is `RESEARCH_MORE`. Approval authorizes Phase 2 planning only; it does not authorize paid APIs, Figma writes, deployment, DNS, purchases, or production changes.
