# Read Me First

This repository builds an evidence-based virtual web-business operating system for one owner. It is phased: a smaller truthful system is preferable to a broad simulated one. `README.md` is the entry point; `02_SYSTEM_ARCHITECTURE.md`, `08_DATA_EVENT_AND_MEMORY_MODEL.md`, and `10_SECURITY_COST_AND_GOVERNANCE.md` define non-negotiable constraints. `PHASE_STATUS.md` reports only verified reality.

The current goal is the first vertical slice: start a research workflow, collect real permitted public evidence, evaluate at least three opportunities, inspect evidence, approve/reject, and create a queued design-preparation project. External integrations remain unavailable until configured and verified.
