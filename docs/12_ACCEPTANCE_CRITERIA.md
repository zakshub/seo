# Acceptance Criteria

The first slice passes when an authenticated owner can create, pause, resume, stop, and inspect a research workflow; at least three opportunities have permitted real evidence; evaluations are inspectable; approval alone creates a Project and queues design preparation; and events/activity are persisted and streamed. Tests cover idempotency, transition validity, event order, permissions, approvals, budget refusal, redaction, unavailable providers, and evidence integrity.

No fake source result, metric, design, deployment, GitHub activity, or provider success is acceptable. A source failure must be visible as incomplete/unavailable.
